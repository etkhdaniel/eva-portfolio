# Eva Daniel Personal Website

Static portfolio site for `evadaniel.com`, designed for GitHub Pages.

## Publish on GitHub Pages

1. Create a GitHub repository named `evadaniel.github.io`, or use any repo with Pages enabled.
2. Add everything in this `site` folder to the repository root.
3. In GitHub, open **Settings > Pages**.
4. Set the source to the default branch and `/root`.
5. In **Custom domain**, enter `evadaniel.com`.
6. At your DNS provider, point `evadaniel.com` to GitHub Pages using GitHub's current DNS instructions.

The included `CNAME` file already contains:

```txt
evadaniel.com
```

## Customize

- Replace placeholder about, work experience, and project text in their matching HTML files.
- Replace the four images in `assets/`.
- Replace `cv.html` with your real CV content, or link the nav item to a PDF.
- Replace `assets/eva-daniel-cv-placeholder.txt` with your real CV when ready.
- Update the email address in `index.html` and `script.js` if needed.
